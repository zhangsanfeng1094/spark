# Integrations Boundary

Owns agent-specific launch/config adapters and launch-time compatibility proxy selection.

Includes:
- `Runner` and `Editor` implementations for Claude, Codex, Grok Build, and OpenCode.
- Registry and names used by CLI/TUI selection.
- API probing and launch-route decisions.
- Calls into `internal/compat/proxy` when an agent requires a local compatibility proxy.
- Uses `internal/compat/proxyutil` only for launch-route logging helpers.

When editing:
- Keep protocol conversion logic in `internal/compat` where possible.
- Keep local HTTP proxy runtime, retries, request decode, streaming HTTP utilities, and proxy logging under `internal/compat/proxy` or `internal/compat/proxyutil`.
- Treat integrations as the layer that decides how to configure and launch an agent.
- Preserve pass-through args from `spark launch ... -- ...`.
- Grok Build launch is always **direct** (no local compat proxy): map profile `openai_api_type` → native `api_backend` (`responses` > `chat_completions` > `messages`) via `grokLaunchRouteForProfile`. Research Grok Build internals with DeepWiki on `xai-org/grok-build`.
