# Configuration Boundary

Owns Spark configuration persistence and translation to/from peer agent configuration files.

Includes:
- Spark `RootConfig`, profiles, integrations, model history, and normalization.
- MCP server storage and merge/import/export operations.
- Codex `config.toml` and Claude `claude.json` read/write support.
- Migration from legacy config shapes.
- File writes that preserve backups where the local helpers already do so.

When editing:
- Keep config model changes paired with load/save/normalize behavior and tests.
- Preserve peer config formats instead of flattening everything into Spark-only assumptions.
- Prefer existing file helpers over direct write logic.
