# TUI Boundary

Owns interactive terminal flows for dashboard, profile management, MCP management, skill management, prompts, and token usage views.

When editing:
- Keep terminal state transitions deterministic and covered by focused tests where possible.
- Match existing Bubble Tea model/update/view patterns.
- Use `scripts/tui-state-navigator.js` and `scripts/tui-state-map.json` when a change affects scripted navigation.
- Avoid mixing config persistence rules into view code beyond existing app-level orchestration.
