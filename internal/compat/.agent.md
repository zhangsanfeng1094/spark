# Compatibility Boundary

Owns protocol translation between client APIs and the upstream OpenAI Chat Completions target, plus the local compatibility proxy runtime that exposes those translations to launched agents.

Key model:
- Client packages parse or write client-specific protocols.
- `internal/compat/ir` is the shared protocol model.
- `internal/compat/policy` handles reasoning and tool compatibility rules.
- `internal/compat/target/openai_chat` maps between IR and OpenAI Chat requests/responses/streams.
- `internal/compat/gateway` orchestrates route selection, HTTP handlers, upstream execution, and stream/non-stream forwarding.
- `internal/compat/proxy` owns local proxy listener/mux/shutdown, upstream URL/key wiring, route registration, usage recorder scoping, and client-specific proxy shells.
- `internal/compat/proxyutil` owns proxy logging/body decoding/rolling logs and streaming HTTP client helpers.

High-risk areas:
- Streaming event order and usage accounting.
- Proxy lifecycle, recorder restore, and shutdown behavior.
- Tool call/tool result IDs and ordering.
- Reasoning preservation, stripping, or provider-specific field names.
- Golden or behavior-sensitive compatibility tests.
