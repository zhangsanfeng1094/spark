# Compatibility Boundary

Owns protocol translation between coding agent client protocols (Codex Responses, Anthropic Messages, Gemini generateContent) and upstream LLM providers via Bifrost Core engine, plus the daemon and in-process compatibility proxy runtimes.

Architecture:
- `internal/compat/engine`: Bifrost core client singleton, plugin lifecycle, provider profile mapping, key binding, and mapping client-native model ids onto profile aliases.
- `internal/compat/ingress/codex`: Adapts Codex `/v1/responses` JSON requests to `schemas.BifrostChatRequest` and streams responses back as Codex SSE events.
- `internal/compat/ingress/claude`: Adapts Anthropic `/v1/messages` JSON requests to `schemas.BifrostChatRequest` and streams responses back as Anthropic SSE events.
- `internal/compat/ingress/gemini`: Adapts Gemini `/v1beta/models/{model}:generateContent` JSON requests to `schemas.BifrostChatRequest` and streams responses back as Gemini SSE events. Client-native model ids are mapped onto profile aliases. If the upstream chat stream fails, the handler retries non-stream and emits Gemini SSE from the complete response.
- `internal/compat/daemon`: Shared background daemon server (default port 42337) multiplexing requests across launched agent sessions with dynamic profile routing. `EnsureDaemon` restarts the process when the running binary identity (version, path, mtime, size) does not match the current Spark executable.
- `internal/compat/proxy`: In-process compatibility proxy fallback (per-process ephemeral port).
- `internal/compat/proxyutil`: Streaming HTTP client helpers, log sanitization, and rolling log support.

Key constraints:
- Token usage is written to `internal/usage` on request completion (streaming & non-streaming) with error logging.
- Session logs are tagged and directed to sanitized log paths.
