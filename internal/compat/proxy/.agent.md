# Compatibility Proxy Boundary

Owns the in-process local HTTP proxy runtime used to adapt launched agents to upstream LLM providers via the Bifrost engine and ingress handlers.

Includes:
- Ephemeral listener, mux, graceful shutdown, rolling/session logging.
- Direct mounting of `ingress/codex.Handler`, `ingress/claude.Handler`, and `ingress/gemini.Handler`.
- In-process fallback mode when shared daemon is disabled (`SPARK_SHARED_PROXY=0`) or unavailable.

When editing:
- Keep protocol request translation and SSE stream conversion inside `internal/compat/ingress/{codex,claude,gemini}`.
- Keep upstream engine orchestration inside `internal/compat/engine`.
- Usage accounting is handled directly within ingress handlers via `usage.AppendDefault`.
