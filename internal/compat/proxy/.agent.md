# Compatibility Proxy Boundary

Owns the local HTTP proxy runtime used to adapt launched agents to upstream OpenAI-compatible gateways.

Includes:
- Shared listener, mux, shutdown, logging, upstream HTTP client, and upstream JSON POST helpers.
- Codex Responses and Anthropic Messages proxy shells.
- Proxy-scoped usage recorder install/restore.
- Client-specific fallback/retry policies that are tied to local proxy execution.

When editing:
- Keep protocol field parsing/writing in `internal/compat/client/*`, `internal/compat/target/*`, `internal/compat/ir`, and `internal/compat/policy`.
- Keep route orchestration and stream/non-stream forwarding in `internal/compat/gateway`.
- Keep launched-agent selection and command/env setup in `internal/integrations`.
- Add lifecycle tests for listener routes, shutdown, recorder restore, and upstream request headers when touching proxy runtime.
