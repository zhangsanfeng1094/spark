# Compatibility Proxy Utilities Boundary

Owns low-level helpers shared by compatibility proxy runtime and launch-route logging.

Includes:
- Request body decoding for plain, gzip, and zstd JSON.
- JSON/log redaction helpers and truncation.
- Daily rolling proxy log files.
- Streaming HTTP client construction.

When editing:
- Keep helpers protocol-neutral when possible.
- Do not add agent launch decisions here; those belong in `internal/integrations`.
- Do not add route orchestration here; that belongs in `internal/compat/gateway` or `internal/compat/proxy`.
