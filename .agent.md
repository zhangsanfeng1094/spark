# Spark Repository Anchor

Spark is a Go CLI for launching AI coding agents with configurable OpenAI-compatible gateways, local profile/config persistence, interactive TUI flows, skill management, MCP transfer, and compatibility proxy translation.

Use this anchor for repository-wide orientation only. Prefer a nearer `.agent.md` when working under a specific boundary.

Primary boundaries:
- `internal/app`: Cobra CLI commands and high-level workflows.
- `internal/config`: Spark config, profile, MCP, Codex TOML, and Claude JSON persistence.
- `internal/integrations`: Agent launch/config adapters, API probing, and launch-route decisions.
- `internal/compat`: Protocol translation plus local compatibility proxy runtime via client codecs, shared IR, policy, gateway, proxy, proxy utilities, and OpenAI Chat target adapters.
- `internal/tui`: Bubble Tea terminal views and interaction helpers.
- `internal/skills`: Skill catalog, registry, install, roots, manifests, and peer sync.
- `internal/usage`: Token usage storage and summaries.
- `npm`: JavaScript launcher and npm package publishing wrapper.

Default verification:
- Go behavior: `go test ./...`
- Release/package edits: inspect `.goreleaser.yml`, `.github/workflows/release.yml`, `release-please-config.json`, and `npm/package.json`.

Repository rule:
- Code and tests are authoritative. Files under `.ai/` summarize and route context, but must be updated or treated as stale when code disagrees.
